# Repo Feed

Веб-демо для поиска проектов на GitHub. Перелистывай карточки мышью, пальцем или стрелками: влево — пропустить, вправо — сохранить. Нажми на название, чтобы открыть репозиторий, или на «Краткая сводка», чтобы узнать, для чего пригодится проект.

- **Обзор** показывает карточки по теме. Попробуй `machine-learning`, `rust` или `web`.
- **Для вас** подбирает проекты по темам из сохранённых карточек.
- **Каталог** показывает подборку списком.
- **Сохранённые** и **История** хранятся в этом браузере.

Открой `index.html` в браузере. Сборка, сервер и ключ API не нужны. У демо локальная подборка из 17 репозиториев, условные счётчики и заранее подготовленные сводки. Обложки загружаются с GitHub. Если сеть недоступна, демо показывает локальную обложку.

Автор проекта — **vladstalker2027-stack**.
